BITCOIN K.SUSHANTA Portal

Step-by-step guide: manager & customer account creation, PIN setup, transactions, and viewing history — explained clearly.

1) Bank Manager Account Creation

Open registration → choose “Bank Manager” → enter details → system auto-generates Account No (BTC...), Customer ID (CID...), and sets initial balance 0.

2) Customer Account Creation

Register → choose “Customer” → system auto-creates Account No (BTC...) and Customer ID → credentials are used for login and transactions.

3) Setting 4-Digit PIN

Go to “Set PIN” page → enter Manager Account No + PIN twice → saved securely in demo (localStorage). Use for Manager login.

4) Transaction Workflow

Whenever rent, bill, or purchase occurs → amount auto-debits payer → credits Manager → records transaction in storage with date/time.

5) View Transaction History

Enter any Account No to view all related transactions — shows from, to, amount, date, and type.

6) Security Notice

LocalStorage is demo-only. For real use: encrypt data, hash PINs, use server-based storage, and HTTPS.
